## Как объяснить подход на защите

1. Backend и API-доступ проверяются pytest, поскольку есть модели, JWT и роли.
2. Frontend-компоненты проверяются Vitest быстро и воспроизводимо.
3. k6 используется для HTTP-нагрузки и latency-порогов.
4. Исследовательский тестирование обнаруживает бизнес-дефекты вне формальных сценариев.
5. Ручной UI-прогон нужен для responsive layout и воспринимаемых пользователем ошибок.
6. Docker обеспечил одинаковую среду backend и frontend.
