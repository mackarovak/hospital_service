## API и безопасность

- [ ] Все protected endpoints требуют JWT
- [ ] Неверный role отклоняется
- [ ] Пациент не читает doctor endpoints
- [ ] Врач не читает patient endpoints
- [ ] Невалидный JSON возвращает 400
- [ ] Несуществующий endpoint возвращает 404
- [ ] Недопустимый HTTP-method возвращает 405
- [ ] Чужой resource возвращает 403
- [ ] Duplicate-данные возвращают корректную ошибку
- [ ] No-store для чувствительных ответов проверен
- [ ] Нет JWT или пароля в логах
- [ ] Нет технических stack trace во frontend ответах
