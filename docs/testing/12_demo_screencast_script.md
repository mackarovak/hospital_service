# Сценарий скринкаста на защиту

Длительность: 3–5 минут.

## 1. Запуск системы — 30 сек

Показать корень проекта и Docker-контейнеры.

## 2. Вход пациента — 40 сек

- Открыть `http://localhost/login`.
- Ввести `patient1/password`.
- Показать переход в `/patient`.

## 3. Вход врача — 30 сек

- Выйти или открыть отдельный браузер.
- Ввести `doctor1/password`.
- Показать кабинет врача и пациентов.

## 4. Запись или медкарта — 45 сек

Показать профиль пациента или запись на слот.

## 5. Демонстрация дефекта — 45 сек

Через Swagger/HTTP-клиент или curl показать:

- создать два пересекающихся слота 10:00–11:00 и 10:30–11:30;
- показать бронирование прошедшего slot через прямой API-запрос.

## 6. Запуск тестов — 45 сек

Показать:

```bash
make test-backend
make test-frontend
make test-load
```

Или общую проверку:

```bash
make test
```

## 7. Итог — 30 сек

Показать документы: план, ПМИ, отчёт, bug_report и чек-лист.

Сформулировать: автоматизация покрывает backend/API/frontend unit/load, ручной блок — UI/UX и responsive-проверки.
